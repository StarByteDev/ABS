ABS V15.1.3 does not require a new database migration.

Upgrade from V15.1.2:
1. Back up the application and database.
2. Preserve the production .env.
3. Replace the application files.
4. Run: php artisan optimize:clear
5. Smoke-test Rewarded Signal Ads with Google test inventory before enabling production inventory.

Existing V15.1.0-V15.1.2 migrations/tables remain valid.
