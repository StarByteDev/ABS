# Mobile/API Notes — ABS V14.8.14

V14.8.14 is primarily a web UX release. No API route or payload contract is removed. Signal lifecycle phases remain New Signal, Entry Confirmed, Trade Active and Signal Closed; user-facing actions are Review Signal, Open Trade, Monitor Trade and View Result. The guided Binance execution remains a protected LIMIT workflow and reuses the existing server-side risk, balance, permission and TP/SL validation.
